## 2. 사용자 인지 수준별 2-Tier 모드 시스템 (Adaptive Tier System)

아동의 인지 및 언어 발달 수준에 따라 앱 내 연출과 조작 난이도를 2단계로 자동/수동 전환합니다.

| 구분 | **[모드 A] 언어 표현 가능 / 경증 아동** | **[모드 B] 무언어 / 중증 / 감각 예민 아동** |
| :--- | :--- | :--- |
| **나레이션/음성** | 상황 설명 문장형 ("친구가 다른 걸 하고 싶대요") | 1~2음절 키워드 중심 ("친구", "가위바위보!") |
| **선택지(PECS)** | 3지선다 (결합형 딜 / 시간분할 / 정중한 거절) | **대형 2지선다 (직관적 단일 심볼 카드)** |
| **인터랙션 방식** | 스와이프, 타이밍 터치, 스몰토크 핑퐁 | **단순 화면 탭(Tap) 또는 길게 누르기(Hold)** |
| **감정 시각화** | 속마음 자막 + 감정 이모지 + 상황 설명 | **대형 감정 표정 이모지 + 펄스 애니메이션** |
| **감각 필터** | 표준 사운드 & 비주얼 이펙트 | **[감각 보호 모드]: 고주파음 차단, 밝기 안정화** |

## 3. CocoLink 4단계 마스터 학습 파이프라인 (Master Learning Flow)

```
[ Step 1. Pre-Story ] ➔ [ Step 2. Visual Schedule ] ➔ [ Step 3. Model-First ] ➔ [ Step 4. Interactive Simulation ] ➔ [ Step 5. Reward & Bridge ]
   (3인칭 3D 동화)          (상시 5단계 아이콘)          (대비형 곰돌이 관찰)         (1인칭 실사 POV 분기 체험)            (스탬프 북 & 큐카드)
```

### 📍 Step 1: Pre-Story (사회적 상황 개념 형성)
* **목적:** 친구와 의견이 다를 때 왜 싸우지 않고 타협해야 하는지 3인칭 동화로 사전 인지.
* **형식:** 30초 3D 파스텔 톤 애니메이션 (마리오 3D 월드 비닐 질감).
* **내용:** 코코와 친구들이 등장하여 갈등 상황과 '딜(Deal)'의 즐거움을 소개.

---

### 📍 Step 2: Visual Schedule (상시 5단계 일정표 HUD)
* **목적:** 아이에게 "언제 끝나고 놀 수 있는지" 전체 5단계를 화면 상단에 상시 노출.
* **화면 상단 UI 구성 예시:**
  ```
  [ 🗣️ 1. 대화 ] ➔ [ ✌️ 2. 가위바위보 ] ➔ [ 🤝 3. 딜 만들기 ] ➔ [ 🎮 4. 함께 놀기 ] ➔ [ 🎁 5. 보상 ]
  ```
* **동작 규칙:** 현재 단계는 1.2배 스케일 업 + 노란색 펄스 테두리, 완료된 단계는 초록색 체크(✅).

---

### 📍 Step 3: Model-First (코코의 대비 모델링 관찰)
* **목적:** 관찰 학습(Modeling)을 통해 실패하는 행동과 올바른 행동의 결과를 3인칭으로 사전 확인.
* **구성:**
  * **[1단계 - 서툰 행동]:** 코코가 장난감을 뺏으려다 친구가 울음 ➔ 화면 정지 및 속마음 팝업 `[💭 "슬퍼!"]`
  * **[2단계 - 성공 행동]:** 리와인드 후 코코가 "가위바위보 하자!" 제안 ➔ 이긴 친구 먼저, 다음 코코 차례 ➔ 하이파이브 성공.

---

### 📍 Step 4: Interactive POV Simulation (1인칭 실사 분기 체험)
* **목적:** 실제 어린이집/놀이터 실사 1인칭 카메라 시점에서 아동이 직접 손을 뻗어 선택하고 실행.
* **핵심 상호작용 메커니즘:**
  1. **💭 Thought Bubble Overlay:** 상대방 머리 위 속마음 말풍선 자동 트래킹.
  2. **🃏 PECS Action Card:** 최소 120x120px 이상의 고대비 카드 2종 제시.
  3. **⏱️ Hold & Release QTE:** 3초 카운트다운 동안 화면을 누르며 차례 대기.
  4. **🛡️ No-Fail Redirect:** 오답 선택 시에도 비난 없이 "다시 해볼까요?" 긍정 피드백 제공.

---

### 📍 Step 5: Reward & Home Bridge (보상 및 가정 전이)
* **스탬프 북:** 에피소드 클리어 시 `[🏆 협상의 달인]`, `[💖 공감 천사]` 등 캐릭터 스티커 쿵!
* **모바일 큐카드:** 외출 전 스마트폰 잠금화면이나 위젯으로 띄울 수 있는 핵심 PECS 카드 1장 자동 생성.
