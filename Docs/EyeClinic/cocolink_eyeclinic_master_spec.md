# [마스터 기획서] CocoLink: 언어·인지 발달지연 아동을 위한 소아 안과 적응 인터랙티브 시스템

> **문서 버전:** v2.1 (점진적 실사화 `2D 동화 ➔ 3D 시연 ➔ 1인칭 실사` 파이프라인 적용)  
> **주요 대상:** 3~9세 발달지연, 자폐스펙트럼(ASD), 무언어/언어 지연 및 낯선 기계·안과 공포감이 극심한 아동  
> **핵심 가치:** "눈이 반짝! 아프지 않고 신기해요!" — 2D/3D/실사 단계적 인지 사다리 기반 안과 적응 솔루션

---

## 1. 기획 배경 및 시스템 목표

### 1.1 기획 배경
* **낯선 대형 검사 기계와 물리적 구속감:** 자동굴절검사기(Auto-Refractor)나 안압계 등 커다란 기계에 턱을 올리고 이마를 밀착해야 하는 과정에서 극심한 구속감과 거부 반응(몸부림, 멜트다운)이 발생합니다.
* **어두운 암실과 강한 불빛:** 안과 진료실 특유의 어두운 조명과 세극등 현미경의 강한 빛은 시각 민감 아동에게 공격적인 위협으로 다가옵니다.
* **예측 불가능한 감각 자극:** "칙!" 하고 눈에 뿜어지는 안압 측정 공기(Air-puff)와 차가운 안약 점안은 사전 예고가 없으면 극심한 공포와 트라우마를 유발합니다.
* **언어적 시력 검사의 한계:** 숫자나 기호를 언어로 말해야 하는 기존 시력표는 무언어·언어지연 아동의 정확한 시력 측정을 불가능하게 만듭니다.

### 1.2 시스템 목표
1. **점진적 실사화(Stepped Realism):** `2D 동화` ➔ `2D UI 일정표` ➔ `3D 공간/기계 시연` ➔ `1인칭 실사`로 이어지는 인지 사다리를 통해 현실 안과 기계에 자연스럽게 적응시킵니다.
2. **예측 가능성(Predictability) 확보:** 5단계 단순 픽토그램 시각적 일정표(Visual Schedule)로 검사 순서와 끝나는 시점(보상)을 명확히 인지시킵니다.
3. **언어 장벽 제거 및 PECS 시력 검사:** 문자 대신 친숙한 그림 기호(오리, 나비, 비행기 등)를 화면 터치로 맞추는 직관적 PECS 인터랙션을 제공합니다.
4. **감각 탈감작(Desensitization) 및 정직한 예고:** 🎈 열기구 보기, 🌬️ 바람 자극, 💡 반짝이는 불빛, 💧 시원한 안약을 2초 전에 미리 시각·청각으로 예고하여 신뢰를 형성합니다.

## 2. 사용자 인지 수준별 모드 설계 (Tier System)

아동의 언어 및 인지 능력 수준에 맞춰 2가지 조절 모드를 제공합니다.

| 분류 | **[모드 A] 언어·인지 경증 / 표현 가능** | **[모드 B] 무언어·인지 중증 / 감각 민감** |
| :--- | :--- | :--- |
| **대화/나레이션** | 쉬운 문장 형태 ("열기구를 가만히 바라볼까요?") | 단어 단위 + 핵심 억양 ("열기구!", "반짝!") |
| **선택지 수** | 3개 선택지 제공 | **최대 2개 선택지 (그림 카드)** |
| **인터랙션** | 그림 카드 + 3초 유지(Hold) QTE | 커다란 영역 탭(Tap) 또는 단순 터치 |
| **안과 검사 연출** | 전체 검사 (열기구 ➔ 안압 ➔ 시력 ➔ 세극등 ➔ 안약) | 핵심 검사 간소화 (열기구 ➔ 그림 시력 ➔ 불빛 관찰) |

---

## 3. CocoLink 4단계 학습 파이프라인 (Master Pipeline)

```
[ Step 1. Pre-Story ] ➔ [ Step 2. Visual Schedule ] ➔ [ Step 3. Model-First ] ➔ [ Step 4. Interactive Simulation ]
   2D 파스텔 동화/그림책          2D 단순 UI 픽토그램          3D 캐주얼 모델링 시연             1인칭 Photorealistic 실사
(심리적 이완 & 개념 형성)        (인지 부하 없는 일정 안내)     (입체 기계/공간 적응 완충)            (실제 현실 직접 체험)
```

---

### 📍 Step 1: Pre-Story (2D 보노보노풍 동화: 안과는 눈을 반짝이게 해줘요)
* **목적:** 병원/안과라는 장소가 무서운 곳이 아니라 안전하고 편안한 곳이라는 기본 개념을 형성.
* **형식:** **2D 미니멀 카툰 동화 (Bonobono Anime Aesthetic, 30초)**
* **시각적 특징:** 자극 없는 플랫 파스텔 단색 톤, 단순한 점 눈과 귀여운 라인, 따뜻한 노란 스카프를 맨 아기 곰돌이 '코코'와 엄마 곰돌이.
* **주요 내용:**
  1. 눈을 깜빡이고 비비는 코코(땀방울 💦)에게 엄마가 "안과에 가서 눈을 시원하게 진료받자!" 다정하게 안내.
  2. 안과 건물의 친근한 모습과 다정한 의료진 소개.
  3. 의사 선생님이 반짝이는 불빛을 보여주고 멋진 별 안경을 선물해주는 이야기 (코코의 방긋 웃는 'ㅅ' 입).

---

### 📍 Step 2: Visual Schedule (2D UI 상시 시각 일정표)
* **목적:** 인지 부하 없이 "언제 집에 가는지" 순서와 완료 상태를 직관적으로 전달.
* **형식:** **단순하고 선명한 2D 픽토그램 / 이모지 HUD**
* **화면 상단 UI 구성:**
  ```
  [ 🏥 1. 입구 ] ➔ [ 📋 2. 접수 ] ➔ [ 🎈 3. 기계 검사 ] ➔ [ 👁️ 4. 진료실 ] ➔ [ 🕶️ 5. 보상 ]
  ```
* **동작 방식:** 현재 단계 반짝임 + 완료된 단계 초록색 체크 표시(✅).

---

### 📍 Step 3: Model-First (3D 캐주얼 모델링: 곰돌이의 안과 체험 관찰)
* **목적:** 2D 동화에서 ➔ 1인칭 실사로 넘어가기 전, **입체 기계(자동검사기, 턱받침, 안압 바람)의 부피감과 공간감을 3D 장난감 그래픽으로 사전 체험(완충 브릿지).**
* **형식:** **3D 캐주얼 애니메이션 (Mario 3D World / Toy-like Vinyl Texture, 45초)**
* **캐릭터 연속성:** Step 1의 2D 코코와 동일한 **'노란 스카프 + 따뜻한 갈색 털'**을 가진 3D 코코 곰돌이.
* **주요 내용:**
  1. 3D 코코가 검사기 턱받침에 턱을 편안하게 착 올리고 이마를 댐.
  2. 렌즈 속 빨간 열기구를 보며 "바람이 퐁~" 나와도 "간지러워!" 방긋 웃음.
  3. 의사 선생님의 불빛 검사를 잘 마치고 번쩍이는 금빛 별 선글라스를 받으며 신나게 브이(V) 포즈.
* **전환 나레이션:** *"동화책 속 코코도 멋지게 해냈어요! 이제 우리 차례예요, 출발!"*

---

### 📍 Step 4: 1인칭 실사 인터랙티브 에피소드 (Interactive Simulation)

#### 🎬 6개 챕터 종합 흐름표

| 챕터 | 진행 장소 | 그래픽 형식 | 핵심 인터랙션 (PECS / QTE) | 상태 변화 (신뢰도/불안도) |
| :--: | :--- | :---: | :--- | :--- |
| **C1** | 안과 입구 | 실사 POV | [👋 인사하기] / [🤝 손잡기] PECS 카드 선택 | 신뢰도 ↑ / 불안도 ↓ |
| **C2** | 접수 & 대기실 | 실사 POV | [🦆 오리] / [🦋 나비] 그림 시력표 터치 탐색 | 대기 안정감 ↑ |
| **C3** | 예비 검사실 | 실사 POV | **3-A:** 턱/이마 대기 (3초 Hold QTE)<br>**3-B (열기구):** 🎈 열기구 화면 터치 응시<br>**3-C (안압):** 🌬️ 바람 사전 예고 + 눈 깜빡임 | 기계 거부감 해소 |
| **C4** | 시력 검사실 | 실사 POV | 그림 시력표 PECS 터치 매칭 (오리/비행기/나비) | 성취감 & 협조도 ↑ |
| **C5** | 안과 진료실 | 실사 POV | **5-A (신뢰):** 💡 불빛 예고 + 펜라이트/세극등 응시<br>**5-B (달래기):** 곰돌이 시연 + 눈 깜빡 복식 호흡<br>**5-C (안약):** 💧 시원한 안약 예고 + 3초 눈 감기 | 진료 순응 완성 |
| **C6** | 보상 & 귀가 | 실사 POV | [🕶️ 멋진 안경] / [⭐ 반짝 별] 보상 스티커 탭 | 성공 경험 확립 |

## 4. UI/UX 및 인터랙션 디자인 규칙

1. **PECS(그림 교환 통신) 버튼 디자인:**
   * 모든 선택지는 텍스트 대신 **크고 명확한 그림 아이콘 + 짧은 단어(1~2음절)** 표기.
   * 예: `[인사 👋]` / `[열기구 🎈]` / `[오리 🦆]`
2. **사전 감각 예고 시스템 (Sensory Warning):**
   * 자극이 오기 2초 전, 화면 구석에 작은 예고 팝업 및 효과음 재생:
     * 🎈 열기구 보기 ➔ 🎈 `열기구 찾기!`
     * 🌬️ 안압 측정 ➔ 🌬️ `바람 칙!` (깜짝 놀라지 않게 솔직하게 예고)
     * 💡 불빛 검사 ➔ 💡 `반짝 불빛!`
     * 💧 안약 넣기 ➔ 💧 `시원한 물방울 퐁!`
3. **오류 없는 디자인 (No-Fail Design):**
   * 제한 시간이 지나거나 터치를 놓쳐도 "실패"나 부정적 피드백 없음.
   * 의사/검안사 선생님이 "괜찮아, 열기구가 어디 있나 다시 찾아볼까?"라며 따뜻하게 기다려주는 루프 연출.
