# [상세 시나리오] CocoLink 화용 심화: "속마음으로 둘까? 💭 vs 말로 할까? 💬"
## : Everyday Speech의 대표작 "Think It or Say It" — 소셜 필터(Social Filter) 인터랙티브 시뮬레이션

> **에피소드 코드:** `EP-21-THINK-OR-SAY`  
> **기준 레퍼런스:** Everyday Speech - *Think It or Say It* (https://www.youtube.com/watch?v=NLm2BuW73m4)  
> **핵심 화용 기술:** 소셜 필터링(Social Filter), 생각 말풍선(💭)과 입 말풍선(💬) 구분, 상대방 감정 상처 방지  
> **타깃 상황:**
> - 발달지연/ASD 아동이 필터 없이 떠오르는 대로 직설적으로 말해 상대방에게 상처를 주는 상황
> - 예: "너 옷 촌스러워", "선생님 살쪘어요", "이 음식 맛없어", "너 그림 진짜 못 그린다"
> 
> **상태 변수:**
> - `social_filter_score` (소셜 필터링 성공률: 0~100)
> - `peer_emotional_impact` (상대방 상처/호감도: -50 ~ +50)
> - `filter_checkpoint_passed` (3대 필터 검문소 통과 여부: Boolean)

│ 💭 생각 말풍선 (Brain)│ 🛡️ 소셜 필터 검문소  │ 💬 입 말풍선 (Mouth)     │
│ "머릿속에 떠오른 생각" │ [3가지 황금 질문]     │ "입 밖으로 나오는 말"     │

## 3. 씬별 상세 연출 및 인터랙션 대본

### 🎬 Scene 01. 인트로: 내 머릿속의 생각 주머니와 소셜 필터
* **화면 연출:** 코코 곰돌이의 머리 위에 구름 모양의 **[💭 생각 주머니]**와 입술 모양의 **[💬 말문]**이 나타남.
* **나레이션:**
  > "우리는 하루에도 수백 가지 생각을 해요! '저 옷 신기하다', '배고프다', '저 장난감 별로야'.  
  > 생각은 자유롭게 할 수 있지만, **모든 생각을 다 입 밖으로 말하면 친구가 상처받을 수 있어요.**  
  > 우리 입 앞에는 소중한 친구의 마음을 지켜주는 **'소셜 필터'**가 있답니다!"

---

### 🎬 Scene 02 & 03. 실전 상황 1: 친구의 짧아진 머리스타일
* **화면 연출 (POV):** 교실. 단짝 친구 유나가 앞머리를 너무 짧게 삐뚤빼뚤 자르고 와서 쑥스러운 표정으로 서 있음.
* **내 머릿속에 떠오른 생각 (Thought Bubble):**
  * 머리 위에 번쩍 `[💭 "유나 앞머리 진짜 이상하고 웃기다! 바가지 같아!"]` 팝업.
* **소셜 필터 검문소 (The Filter Checkpoint):**
  * 화면이 일시 정지되며 입술 앞에 황금색 방패 필터 등장.
  * **질문 1:** "이 말을 그대로 하면 유나 기분이 어떨까?" ➔ `[슬프고 울 것 같다 😢]` 탭.
* **선택 인터랙션:**
  ```
  +----------------------------------+    +----------------------------------+
  |    [ 💭 머릿속에 쏙 넣어두기 ]    |    |     [ 💬 입 밖으로 소리치기 ]    |
  |  (말하지 않고 그냥 "안녕 유나야!")|    |   "푸하하! 앞머리 진짜 웃기다!"  |
  +----------------------------------+    +----------------------------------+
  ```
* **분기 연출:**
  * **[머릿속에 쏙 선택]:** 생각 말풍선을 손가락으로 콕 찍어 머리 안으로 쏙 집어넣는 애니메이션! ➔ 유나에게 "안녕 유나야!" 따뜻하게 손인사 ➔ 유나가 안도하며 활짝 웃음 (`peer_emotional_impact: +30`).
  * **[입 밖으로 소리치기 선택]:** 유나의 눈에 눈물이 글썽이며 도망침 ➔ 화면 리와인드 후 "친구가 상처받았어요. 머릿속에만 간직해 볼까요?" 피드백.

---

### 🎬 Scene 04 & 05. 실전 상황 2: 마음에 안 드는 간식이나 선물
* **화면 연출 (POV):** 친구 지호가 자기 집에서 가져온 당근 머핀을 내 손에 쥐여주며 "내가 엄마랑 만든 거야! 맛있게 먹어!"라고 함.
* **내 생각:** 한 입 베어 물었는데 맛이 없고 냄새가 마음에 안 듦.
* **떠오른 직설적 생각:** `[💭 "우웩! 이거 맛없어! 똥 냄새나!"]`
* **소셜 필터 변환 인터랙션 (Refining the Speech):**
  * "내 생각은 맛이 없지만, 친구의 정성을 생각해서 어떻게 말하면 좋을까요?"
  * **PECS 변환 선택:**
    ```
    [ ❌ 필터 없는 말 ] : "맛없으니까 너나 다 먹어!"
          ⬇️ (소셜 필터 통과!)
    [ ⭕ 예의 바른 말 ] : "만들어줘서 고마워! 그런데 지금 배가 불러서 나중에 먹을게."
    ```
* **결과 연출:** 예의 바른 카드를 선택하자 지호가 "그래! 고마워!" 하며 기분 좋게 돌아감.

---

### 🎬 Scene 06. 실전 상황 3: 친구가 체육 시간에 실수를 했을 때
* **화면 연출 (POV):** 체육 시간 이어달리기. 앞 주자인 친구가 달리다 넘어져서 바통을 떨어뜨림.
* **떠오른 생각:** `[💭 "너 때문에 졌잖아! 진짜 못 뛰어!"]`
* **소셜 필터 인터랙션:**
  * 화면의 [격려 확성기 📣]를 탭하여 생각 전환.
  * **선택지:** `[💬 "괜찮아! 다치지 않았어?"]`
* **결과 연출:** 1인칭 손으로 넘어진 친구를 일으켜 세워줌 ➔ 친구가 감동하며 손을 잡음 (`social_filter_score: 100`).

---

### 🎬 Scene 07. 보상 및 피드백 (Social Filter Master)
* **화면 연출:** 교실의 모든 친구들이 엄지손가락을 치켜세우며 "OO이랑 있으면 마음이 편안해!" 칭찬.
* **보상:** `[🛡️ 황금 소셜 필터 마스터 배지]` 획득!
