# [스토리보드 & 프롬프트 명세] CocoLink 에피소드 14 & 17: 공중화장실과 어린이집 급식 배식
## : Everyday Speech식 감각 과민(Sensory Sensitivity) 대처 & 기관 단체생활 루틴

> **에피소드 코드:** `EP-14-BATHROOM-ROUTINE` & `EP-17-CAFETERIA-MEAL`  
> **핵심 주제:** 전환 및 일상 루틴 — 공중화장실 핸드드라이어/자동 물내림 소음 극복, 급식판 들고 자리 앉기, 안 먹는 반찬 정중히 거절하기  
> **상태 변수:**
> - `sensory_noise_tolerance` (소음 감각 내성: 0~100, 목표: 70 이상)
> - `cafeteria_routine_score` (급식 루틴 완수율: 0~100)
> - `independent_toilet_score` (화장실 자립도: 0~100)

## PART 1. [EP-14] 공중화장실 탐험: "핸드드라이어 괴물 소리와 손 씻기"

발달지연/ASD 아동이 가장 큰 멜트다운을 겪는 공중화장실의 **돌발적인 고주파 소음(핸드드라이어 굉음, 자동 물내림 '쿠와앙' 소리)** 사전 둔감화.

### 1. 감각 예고 시스템

```
[ 🚽 자동 물내림 ]  ➔  [ 🧼 거품 비누 뽀득 ]  ➔  [ 💨 핸드드라이어 굉음 / 종이타월 ]
  "쿠와앙 소리 3초"        "거품 비누 문지르기"        "귀를 막거나 종이타월 쓰기"
```

### 2. 씬별 상세 연출 대본

#### 🎬 Scene 01. 화장실 입장 및 변기 물내림 (Flushing Sound)
* **사전 예고:** `[🚽 2초 뒤: 쿠와앙~ 시원한 물소리!]`
* **연출:** 변기 레버를 누르자 큰 소리로 물이 내려감.
* **코핑 전략 (Coping):** 화면에 `[귀에 손 대기 🎧]` 버튼 노출 ➔ 3초간 양손으로 귀를 살짝 막고 지나가기.
* **나레이션:** "물이 콸콸 내려가며 변기가 깨끗해졌어요! 이제 손을 씻으러 가요."

#### 🎬 Scene 02. 비누칠 20초 뽀득뽀득 (Soap & Wash)
* **화면 연출 (POV):** 세면대 앞. 수도꼭지에서 따뜻한 물이 나옴.
* **인터랙션:** 비누 거품 펌프를 1번 탭 ➔ 화면을 좌우로 문질러(Rub) 손바닥, 손등, 손가락 사이 거품 내기 (생일 축하 노래 멜로디).

#### 🎬 Scene 03. 핸드드라이어 소음 vs 종이타월 선택 (Drying Hands)
* **상황:** 세면대 옆에서 다른 사람이 핸드드라이어를 켜서 `위이이잉---!` 굉음 발생.
* **PECS 카드 선택:**
  ```
  +--------------------------+    +--------------------------+
  |    [ 🧻 종이타월 톡톡 ]   |    |    [ 💨 드라이어 3초 ]   |
  |  소리 안 나는 휴지로 닦기|    |    바람에 3초 말리기    |
  +--------------------------+    +--------------------------+
  ```
* **결과 연출:** 
  * `[종이타월]` 선택 시: 조용하게 종이타월을 1장 뽑아 톡톡 닦고 휴지통에 쏙 넣음 ("소리가 무서울 땐 종이타월을 써도 아주 좋아요!").
  * `[드라이어]` 선택 시: 3초 카운트다운 동안 바람을 쐬고 뽀송뽀송해짐.
* **보상:** `[🧼 손 씻기 청결왕 배지]` 획득.

## PART 2. [EP-17] 어린이집 급식 시간: "급식판 들고 자리 쏙!"

### 1. 씬별 상세 연출 대본

#### 🎬 Scene 01. 두 손으로 급식판 받기 (Carrying the Tray)
* **화면 연출 (POV):** 배식대 앞. 조리사 선생님이 밥과 국, 반찬이 담긴 식판을 건넴.
* **인터랙션 (Two-Hand Tap):** 화면 좌/우 양쪽 손잡이 영역을 **동시에 2초간 탭**하여 균형 잡기.
* **결과:** 국물이 쏟아지지 않고 안전하게 내 자리로 이동.

#### 🎬 Scene 02. 싫어하는 반찬 정중하게 거절/조절하기 (Food Refusal/Adjustment)
* **화면 연출 (POV):** 식판에 초록색 브로콜리/파프리카가 보임.
* **내면 감정:** "이건 냄새가 낯설어서 먹기 싫은데..."
* **PECS 카드 선택:**
  ```
  +--------------------------+    +--------------------------+
  |    [ 🥦 1개만 맛볼게요 ]  |    |     [ 💥 식판 엎기 ]     |
  |  "선생님, 1개만 먹을래요" |    |    반찬을 바닥에 던지기  |
  +--------------------------+    +--------------------------+
  ```
* **결과 연출:** `[1개만 맛볼게요]` 선택 시 선생님이 "스스로 먹을 만큼 조절해서 말했구나! 멋져!" 칭찬 (루틴 완수 +30).

#### 🎬 Scene 03. 식사 후 퇴식구 정리 (Clean Up)
* **화면 연출:** 숟가락, 젓가락을 식판 위에 모으고 퇴식구 통에 쏙 넣기 (Swipe Up 인터랙션).
* **보상:** `[🍱 얌얌 급식 매너왕 배지]` 획득!
