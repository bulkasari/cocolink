# [실전 시나리오 03] 이겼을 때와 졌을 때의 스포츠맨십
## : "좋은 승부였어!" — Fast Track Session 16 기반 승패 시 말하기 훈련

> **원전 레퍼런스:** 《Fast Track Friendship Group Manual》 Unit IV, Session 16 (Good Things to Say When You Win or Lose)  
> **에피소드 코드:** `FT-03-SPORTSMANSHIP-TALK`  
> **핵심 화용 기술:**
> 1. 이겼을 때 잘난 척하거나 놀리지 않고 겸손하게 상대방을 격려하기 (Good Winner)
> 2. 졌을 때 화내거나 판을 엎지 않고 상대를 씩씩하게 축하해주기 (Good Loser)
> 
> **상태 변수:**
> - `sportsmanship_score` (스포츠맨십 지수: 0~100)
> - `bragging_inhibition` (자랑/놀림 억제도: 0~100)
> - `peer_friendship_retention` (우정 유지도: 0~100)

## 1. Fast Track 스포츠맨십 황금 대화법 (The Golden Sayings)

```
┌──────────────────────────────────┬──────────────────────────────────┐
│        🏆 내가 이겼을 때 (Win)    │        🥈 내가 졌을 때 (Lose)    │
├──────────────────────────────────┼──────────────────────────────────┤
│ ⭕ "너도 정말 잘했어! 아슬아슬했어!"│ ⭕ "축하해! 진짜 멋진 경기였어!" │
│ ⭕ "재미있었어, 한 판 더 할까?"   │ ⭕ "다음엔 내가 이길 거야, 한 판 더!"│
├──────────────────────────────────┼──────────────────────────────────┤

└──────────────────────────────────┴──────────────────────────────────┘
```

## 2. 씬별 상세 연출 및 인터랙션 대본

### 🎬 Part 1. 내가 이겼을 때의 상황 (Case: I Won!)
* **화면 연출 (POV):** 주사위 보드게임 결승선에 내 말이 먼저 도착함.
* **상대 친구(민재) 표정:** 입술이 삐죽 나오고 고개를 푹 숙이며 시무룩해함.
* **내면 충동:** "야호! 내가 이겼다! 너 완전 못해! 꼴찌다!" 놀리고 싶은 충동.
* **속마음 말풍선:** 민재 머리 위 `[💭 "나도 이기고 싶었는데... 놀림당하면 너무 창피해"]` 🥺
* **PECS 카드 선택:**
  ```
  +----------------------------------+    +----------------------------------+
  |  [ 🤝 👍 "너도 진짜 잘했어!" ]    |    |     [ 😝 "메롱! 너 완전 졌지?" ]  |
  |  "끝까지 아슬아슬해서 재밌었어!" |    |    민재 얼굴 앞에서 춤추며 놀리기 |
  +----------------------------------+    +----------------------------------+
  ```
* **결과 연출:** `[너도 잘했어]` 선택 시 민재의 어깨를 툭 치며 하이파이브 ➔ 민재가 부끄럽게 웃으며 "고마워! 너 진짜 잘하더라!" 답함 (`peer_friendship_retention: +40`).

---

### 🎬 Part 2. 내가 졌을 때의 상황 (Case: I Lost!)
* **화면 연출 (POV):** 이번엔 민재의 말이 먼저 결승선에 골인함.
* **민재 대사:** "야호! 내가 골인했다!"
* **내면 감정:** 가슴이 철렁하고 눈물이 핑 돌며 보드판을 엎어버리고 싶은 충동.
* **진정 인터랙션:** 심호흡 1번 `후-` 하고 생각 스위치 켜기: `[💭 게임은 재미로 하는 거야!]`
* **PECS 카드 선택:**
  ```
  +----------------------------------+    +----------------------------------+
  |    [ 👏 🏆 "민재야 축하해!" ]      |    |     [ 💥 보드판 뒤엎기 ]         |
  |  "축하해! 다음 판은 내가 이긴다!"|    |    말을 집어 던지고 울며 소리치기 |
  +----------------------------------+    +----------------------------------+
  ```
* **결과 연출:** `[축하해]` 선택 시 손뼉을 짝짝 치며 "축하해 민재야!" 말함 ➔ 민재가 눈을 반짝이며 "OO아 고마워! 너랑 게임하니까 진짜 재밌다! 한 판 더 하자!" 주사위를 건넴 (`sportsmanship_score: 100`).
* **보상:** `[🏆 황금 스포츠맨십 트로피 배지]` 획득!
