# [마스터 기획서] CocoLink: 언어·인지 발달지연 아동을 위한 소아과 병원 적응 인터랙티브 시스템

> **문서 버전:** v2.0 (교육학적 프레임워크 `educational_direction.md` 반영 완료)  
> **주요 대상:** 3~9세 발달지연, 자폐스펙트럼(ASD), 무언어/언어 지연 및 병원 공포감이 극심한 아동  
> **핵심 가치:** "무섭지 않아요, 순서를 알면 할 수 있어요!" — 4단계 파이프라인 기반 시각/행동 적응 솔루션

---

## 1. 기획 배경 및 시스템 목표

### 1.1 기획 배경
* 병원을 낯설고 무서운 공간으로 인지하는 발달지연 아동은 돌발 행동(비명, 멜트다운, 거부)을 일으켜 진료 및 예방접종에 큰 어려움을 겪음.
* 기존 솔루션은 텍스트 중심이거나 일반 아동용 1인칭으로 구성되어, 인지/언어가 약한 아동에게 오히려 거부감을 줌.

### 1.2 시스템 목표
1. **예측 가능성(Predictability) 확보:** 5단계 시각적 일정표(Visual Schedule)로 진료 과정과 끝나는 시점을 명확히 인지시킴.
2. **언어 장벽 제거:** 텍스트 선택지 대신 AAC/PECS(그림 카드) 방식과 직관적 Touch/Hold QTE 인터랙션 제공.
3. **감각 탈감작(Desensitization):** 청진기, 이경, 주사기 등 의료 기구의 촉감·소리·통증을 사전 예고하여 공포 완화.

---

## 2. 사용자 인지 수준별 모드 설계 (Tier System)

아동의 언어 및 인지 능력 수준에 맞춰 2가지 조절 모드를 제공합니다.

| 분류 | **[모드 A] 언어·인지 경증 / 표현 가능** | **[모드 B] 무언어·인지 중증 / 감각 민감** |
| :--- | :--- | :--- |
| **대화/나레이션** | 쉬운 문장 형태 ("안녕하세요 인사할까요?") | 단어 단위 + 핵심 억양 ("안녕!", "청진기!") |
| **선택지 수** | 3개 선택지 제공 | **최대 2개 선택지 (그림 카드)** |
| **인터랙션** | 그림 카드 + 간단한 타이밍 터치 | 커다란 영역 탭(Tap) 또는 길게 누르기(Hold)만 |
| **주사 씬 연출** | 7단계 절차 (도구 탐색 ➔ 호흡 ➔ 버티기) | 3단계 빠른 순서 (예고 ➔ 버티기 ➔ 반창고) |

## 3. CocoLink 4단계 학습 파이프라인 (Master Pipeline)

```
[ Step 1. Pre-Story ] ➔ [ Step 2. Visual Schedule ] ➔ [ Step 3. Model-First ] ➔ [ Step 4. Interactive Simulation ]
   3인칭 동화/설명          상시 노출 시각 일정표          곰돌이 시연 관찰              1인칭 실사 체험 & 보상
```

---

### 📍 Step 1: Pre-Story (병원은 안전한 곳이에요)
* **목적:** 병원에 가야 하는 이유와 병원이라는 장소의 개념을 3인칭 동화로 사전 형성.
* **형식:** 30초 3인칭 2D/3D 애니메이션.
* **주요 내용:**
  * 쿵쿵 기침 소리와 함께 열이 나는 캐릭터 등장.
  * "아플 때는 병원에 가요. 의사 선생님은 우리를 다정하게 도와주는 친구예요!"

---

### 📍 Step 2: Visual Schedule (상시 시각 일정표 UI)
* **목적:** 진료 전체 진행 상황과 **"언제 집에 가는지"**를 아이콘으로 상시 노출하여 불안 완화.
* **화면 상단 UI 구성:**
  ```
  [ 🏥 입구 ] ➔ [ 📋 접수 ] ➔ [ 🩺 진료 ] ➔ [ 💉 주사 ] ➔ [ 🎁 보상 ]
  ```
* **동작 방식:** 현재 진행 중인 단계의 아이콘이 반짝이고, 완료된 단계는 체크 표시(✅)로 변경.

---

### 📍 Step 3: Model-First (곰돌이의 시연 관찰)
* **목적:** 관찰 학습(Modeling)을 통해 기구 검사에 대한 공포감을 먼저 해소.
* **주요 내용:**
  * 곰돌이 인형이 먼저 의사 선생님을 만남.
  * 의사가 곰돌이 가슴에 청진기를 대고 "차갑지 않지? 간지럽지?" 하며 웃음.
  * 곰돌이가 참 잘해서 칭찬 스티커를 받는 모습을 보여준 후 "이제 OO이 차례야!" 유도.

---

### 📍 Step 4: 1인칭 실사 인터랙티브 에피소드 (Interactive Simulation)

#### 🎬 6개 챕터 종합 흐름표

| 챕터 | 진행 장소 | 핵심 인터랙션 (PECS 그림 카드 / QTE) | 상태 변화 (신뢰도/불안도) |
| :--: | :--- | :--- | :--- |
| **C1** | 병원 입구 | [👋 인사하기] / [🤝 손잡기] 그림 카드 선택 | 신뢰도 ↑ / 불안도 ↓ |
| **C2** | 대기실 | [🐟 어항] / [📚 책] 화면 터치 탐색 미션 | 대기 안정감 ↑ |
| **C3** | 복도 이동 | [🚶 걸어가기] 탭 이동 (카메라 Dolly-In) | 협조도 ↑ |
| **C4** | 진료실 입장 | 의사 선생님 정면 눈맞춤 + [👋 인사] 선택 | 신뢰도 ↑ |
| **C5** | 검사 (선택) | **5-A (신뢰):** 청진기/목/귀 탭 검사<br>**5-B (달래기):** 곰돌이 시연 + 풍선 호흡 QTE<br>**5-C (주사):** 팔 선택 ➔ 호흡 ➔ 버티기 QTE | 협조도 최대치 달성 |
| **C6** | 보상 & 귀가 | [⭐ 별] / [🦕 공룡] / [💜 하트] 스티커 탭 획득 | 보상감 & 성공 경험 확립 |

## 4. UI/UX 및 인터랙션 디자인 규칙

1. **PECS(그림 교환 통신) 버튼 디자인:**
   * 모든 선택지는 텍스트 대신 **크고 명확한 그림 아이콘 + 짧은 단어(1~2음절)** 표기.
   * 예: `[안녕 👋]` / `[숨기 🙈]`
2. **사전 감각 예고 시스템 (Sensory Warning):**
   * 자극이 오기 2초 전, 화면 구석에 작은 예고 팝업 표시:
     * 🩺 청진기 ➔ ❄️ `차갑다!`
     * 🔦 손전등 ➔ 💡 `반짝!`
     * 💉 주사 ➔ 🌵 `따끔!` (솔직하게 예고하여 신뢰 형성)
3. **오류 없는 디자인 (No-Fail Design):**
   * 제한 시간이 지나거나 터치를 놓쳐도 "실패"나 감점 연출 없음.
   * 의사/간호사 선생님이 "괜찮아, 천천히 해보자!"라며 기다려주는 루프 연출.
