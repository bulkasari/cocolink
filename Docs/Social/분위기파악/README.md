# [마스터 가이드] 분위기 파악(Reading the Room) & 사회적 단서(Social Cues)
## : Everyday Speech 기반 상황 맞춤형 행동 조절 3단계 스캔 프레임워크

> **문서 목적:** 공간의 에너지, 사람들의 표정과 소음 크기를 파악하여 나의 행동·목소리·속도를 상황에 맞추는(Matching the Energy) 훈련 가이드  
> **핵심 슬로건:** *"들어가기 전 3초! 눈으로 보고, 귀로 듣고, 내 에너지를 맞춰요!"*

---

## 1. Everyday Speech 3단계 룸 스캔 법칙 (The 3-Step Room Scan)

```
┌────────────────────────────────────────────────────────────────────────┐
│                   분위기 탐정의 3단계 레이더 (Room Radar)                 │
├─────────────────────┬─────────────────────┬────────────────────────────┤
│ 1. Look (눈으로 보기)│ 2. Listen (귀로 듣기)│ 3. Match (행동 맞추기)     │
├─────────────────────┼─────────────────────┼────────────────────────────┤
│ • 사람들의 얼굴 표정│ • 소리 크기 (1~5)    │ • 공간 에너지 레벨에 맞추기 │
│ • 앉아있나? 서있나? │ • 조용한가? 웅성대나?│ • 내 목소리와 걸음걸이 조절│
│ • 무슨 활동 중인가? │ • 진지한가? 웃는가?  │ • 끼어들 타이밍 판단하기   │
└─────────────────────┴─────────────────────┴────────────────────────────┘
```

## 2. 공간 에너지 4대 레벨 (Room Energy Levels)

| 레벨 | 공간 성격 | 대표 상황 | 적정 목소리 (1~5) | 적정 행동 톤 |
| :---: | :--- | :--- | :---: | :--- |
| **Level 1**<br>(정숙·차분) | **Whisper Zone**<br>(아주 조용한 곳) | 도서관, 병원 대기실, 낮잠 시간, 미술관 | **1단계 (귓속말)** | 발끝으로 살금살금, 조용히 책 넘기기 |
| **Level 2**<br>(집중·진지) | **Focus Zone**<br>(집중하는 곳) | 수업 시간, 선생님 설명, 친구가 울 때, 식사 | **2단계 (소곤소곤)** | 제자리에 바르게 앉기, 말할 땐 손들기 |
| **Level 3**<br>(협동·보통) | **Social Zone**<br>(함께 활동하는 곳) | 모둠 활동, 보드게임, 만들기, 복도 이동 | **3단계 (보통 대화)** | 눈 맞추며 차례차례 이야기하기 |
| **Level 4**<br>(활기·자유) | **High Energy Zone**<br>(신나게 뛰는 곳) | 체육관, 놀이터, 생일파티, 자유놀이 | **4단계 (우렁찬 소리)** | 마음껏 뛰고 웃으며 하이파이브! |
