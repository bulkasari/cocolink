## 2. 씬별 상세 연출 대본 및 비디오 생성 명세

### 🎬 Scene 01. Pre-Story (유치원은 즐거운 곳이에요)
* **카메라 & 시점:** 3인칭 와이드 샷 ➔ 유치원 정문 줌인
* **등장인물:** 코코(아기 곰 캐릭터), 코코 엄마
* **음성 나레이션:**
  > "노란 버스를 타고 유치원에 도착했어요! 문을 열고 신발을 쏙 넣으면, 친절한 선생님과 신나는 블록 놀이가 기다려요!"
* **상단 UI:** `[1. 문 열기 🚪] ➔ [2. 신발 정리 👟] ➔ [3. 안녕 인사 👋] ➔ [4. 교실 입장 🏫] ➔ [5. 블록 놀이 🧩]` 활성화.

---

### 🎬 Scene 02 & 03. Contrastive Video Modeling (코코의 등원 시연)

#### [S02: 서툰 행동 관찰 (What Went Wrong)]
* **영상 연출:** 코코가 유치원 현관에서 엄마 다리를 꼭 껴안고 눈물을 글썽이며 떼를 씀.
* **속마음 말풍선 (Thought Bubble):**
  * 코코: `[💭 "엄마 가면 안 돼! 무서워"]` 😟
  * 엄마: `[💭 "엄마 일 끝나고 금방 데리러 올 텐데, 코코가 슬퍼하네"]` 🥺
* **효과:** 화면 흑백 정지 ➔ "코코가 엄마랑 헤어지기 힘든가 봐요. 어떻게 하면 좋을까요?" 나레이션.

#### [S03: 올바른 행동 관찰 (Positive Model)]
* **영상 연출:** 
  1. 선생님이 따뜻하게 미소 지으며 코코의 눈높이에 앉음.
  2. 코코가 가슴에 손을 얹고 깊게 숨을 `후-` 내쉼.
  3. 코코가 엄마에게 손을 흔들며 밝게 웃음 `[👋 "엄마 이따 만나요!"]`.
  4. 신발을 스스로 벗어 자기 이름표가 붙은 칸에 쏙 넣음.
  5. 선생님과 손바닥 하이파이브!
* **나레이션:** "우와! 코코가 씩씩하게 인사하고 신발도 정리했어요! 이제 OO이 차례예요!"

---

### 🎬 Scene 04. 1인칭 POV: 현관문 열기 (Door Entrance)
* **화면 연출:** 1인칭 POV. 따뜻한 우드 톤의 어린이집 현관문 손잡이가 정면에 보임. 문 너머로 아이들의 웃음소리와 실로폰 멜로디가 은은하게 들림.
* **인터랙션 (QTE):** 문 손잡이 주변에 노란색 펄스 링 표시 ➔ **[손잡이 탭(Tap)]**
* **결과 연출:** 문이 부드럽게 스르륵 열리며 환한 실내화 신발장 공간과 담임 선생님이 보임.

---

### 🎬 Scene 05. 1인칭 POV: 신발 벗고 신발장에 넣기 (Shoes Routine)
* **화면 연출:** 1인칭 POV. 발밑에 운동화가 보이고, 바로 앞에 귀여운 동물 이름표가 붙은 신발장 칸이 보임.
* **UI 인터랙션:** 화면 하단 2개 PECS 카드 등장.
  ```
  +--------------------------+    +--------------------------+
  |        [ 👟 ➔ 🗄️ ]        |    |          [ 🧦 ]          |
  |     신발장에 쏙 넣기     |    |      그냥 들어가기       |
  +--------------------------+    +--------------------------+
  ```
* **분기 연출:**
  * **[신발장 선택 시]:** 1인칭 손이 나와 신발을 가지런히 들어 신발장 칸에 쏙 넣는 매끄러운 1인칭 동작. 선생님의 칭찬 음성: "스스로 신발을 정리했네! 최고야!" (루틴 +30, 불안 -20).
  * **[그냥 들어가기 선택 시]:** 선생님이 웃으며 신발장 칸을 가리키며 "신발이 자기 자리를 찾고 싶대요! 쏙 넣어볼까요?" 부드럽게 재유도 (실패 처리 없이 정답 동작 자동 재생).

---

### 🎬 Scene 06. 1인칭 POV: 선생님과 눈맞춤 및 인사 (Greeting)
* **화면 연출:** 담임 선생님이 무릎을 굽혀 1인칭 카메라와 정확히 눈높이를 맞추고 밝게 미소 지음.
* **선생님 대사:** "OO아, 좋은 아침! 오늘 정말 멋지게 왔네!"
* **속마음 말풍선:** 선생님 머리 위 `[💭 "OO이가 와서 정말 기뻐! 재미있게 놀자"]` 😊
* **UI 인터랙션:**
  ```
  +--------------------------+    +--------------------------+
  |          [ 👋 ]          |    |          [ 🙈 ]          |
  |       배꼽손 인사        |    |       얼굴 가리기        |
  +--------------------------+    +--------------------------+
  ```
* **분기 연출:**
  * **[배꼽손 인사 선택]:** 손을 모으거나 손을 흔드는 연출 ➔ 선생님이 양손으로 하이파이브 "안녕!" (친밀도 +30).
  * **[얼굴 가리기 선택]:** 손으로 살짝 가리는 연출 ➔ 선생님이 "조금 쑥스럽구나? 천천히 들어와도 돼!" 하고 따뜻하게 맞이.

---

### 🎬 Scene 07. 1인칭 POV: 엄마와 작별하기 (Separation Routine)
* **화면 연출:** 문밖에서 엄마가 다정하게 손을 흔들며 미소 짓고 있음.
* **엄마 대사:** "우리 OO이 재미있게 놀고 있으면, 엄마가 간식 먹을 때 데리러 올게! 사랑해!"
* **인터랙션 (Hold QTE):** 화면 중앙에 큼직한 `[👋 손 흔들기]` 아이콘 등장.
  * **2초 동안 길게 누르기 (Hold for 2 seconds)**
* **결과 연출:** 누르는 동안 화면 테두리에서 따뜻한 노란빛 하트 파티클이 퐁퐁 솟아오름. 2초 완수 시 손을 활짝 흔들며 엄마가 "안녕!" 하고 웃으며 돌아섬 (불안도 대폭 감소: 60 ➔ 10).

---

### 🎬 Scene 08. 1인칭 POV: 교실 입장 및 보상 (Classroom & Reward)
* **화면 연출:** 선생님 손을 잡고 교실 안으로 발걸음을 옮김. 알록달록한 블록 매트와 장난감이 눈앞에 펼쳐짐.
* **보상 연출:**
  * 화면 상단 Visual Schedule의 5개 아이콘이 모두 황금색 체크(✅)로 점등.
  * `[🌟 슈퍼 등원왕 스탬프]`가 쿵 찍히며 코코의 환호성 사운드.
* **상태 결과:** `routine_completion: 100`, `separation_anxiety: 10`, `teacher_rapport: 70`.
