> **핵심 주제:** 화용 언어 및 일상 규칙 — 마트 물건 만지지 않기, 식당에서 의자에 앉아있기, 엘리베이터 버튼 장난 안 치기

## PART 1. [EP-09] 마트 장보기: "내 손은 카트 손잡이에 쏙!"

### 1. 기대 행동 vs 예상치 못한 행동 (Expected vs Unexpected)
* **Expected (바른 행동):** 카트 손잡이를 잡고 걷기, 엄마가 주는 물건만 카트에 넣기, 원하는 과자는 1개만 고르기.
* **Unexpected (서툰 행동):** 진열대 과자를 마구 뜯거나 집어 던지기, 통로에서 전력 질주하기, 바닥에 눕기.

### 2. 씬별 상세 연출 대본

#### 🎬 Scene 01. 마트 입구 & 역할 부여 (Cart Helper)
* **화면 연출 (POV):** 대형 마트 입구. 반짝이는 과자 코너와 장난감 코너가 보임.
* **엄마 나레이션:** "오늘 OO이는 엄마의 '슈퍼 장보기 도우미'예요! 카트 손잡이를 같이 잡아줄래요?"
* **인터랙션 (Hold QTE):** 화면 하단 카트 손잡이를 2초간 꾹 잡기 ➔ 카트를 밀며 안정적으로 마트 진입.

#### 🎬 Scene 02. 과자 진열대 유혹과 선택 (1개만 고르기)
* **화면 연출 (POV):** 눈앞에 수많은 과자 상자가 진열되어 있음.
* **PECS 카드 선택:**
  ```
  +--------------------------+    +--------------------------+
  |    [ 🍪 1개만 쏙 ]       |    |     [ 🛒 다 쓸어담기 ]   |
  |  "내가 좋아하는 과자 1개"|    |    선반에 있는 것 다 넣기|
  +--------------------------+    +--------------------------+
  ```
* **결과 연출:** `[1개만 쏙]` 선택 시, 가장 좋아하는 초코 과자 1개를 조심스럽게 카트에 쏙 넣음. 엄마의 칭찬: "약속대로 1개만 예쁘게 골랐네! 최고야!" (예절 지수 +30).

#### 🎬 Scene 03. 계산대 줄 서기 & 바코드 삑! (Checkout)
* **화면 연출:** 계산대 컨베이어 벨트 앞.
* **인터랙션 (Tap):** 과자를 집어 벨트 위에 올리기 ➔ 직원분이 바코드를 `삑-!` 찍어줌.
* **보상:** 영수증과 함께 `[🛒 슈퍼 장보기 도우미 배지]` 획득.

## PART 2. [EP-09-B] 식당에서 밥 먹기: "의자에 엉덩이 착!"

### 1. 씬별 상세 연출 대본

#### 🎬 Scene 01. 식당 의자 착석 & 대기 시간 (Waiting for Food)
* **화면 연출 (POV):** 식당 테이블에 앉음. 맛있는 냄새가 나지만 아직 음식이 나오지 않음.
* **속마음 말풍선:** 종업원 머리 위 `[💭 "뜨거운 국물을 나르는 중이에요. 뛰어다니면 다쳐요!"]` ⚠️
* **인터랙션:** 화면 속 색칠 공부 종이 탭하기 (지루할 때 대기 활동).

#### 🎬 Scene 02. 뜨거운 음식 등장과 식사 예절 (Hot Food Safety)
* **사전 예고:** `[🔥 2초 뒤: 김이 모락모락 뜨거운 밥!]`
* **PECS 카드 선택:**
  ```
  +--------------------------+    +--------------------------+
  |      [ 💨 호~ 불기 ]     |    |       [ 🖐️ 손으로 덥석 ]   |
  |     숟가락으로 호~ 불기  |    |     뜨거운 뚝배기 만지기  |
  +--------------------------+    +--------------------------+
  ```
* **결과 연출:** `[호~ 불기]` 선택 시 숟가락으로 밥을 떠서 입으로 `후-` 불어 맛있게 먹음 (예절 지수 +30).

## PART 3. [EP-18] 엘리베이터와 대중교통: "버튼은 우리 층만 1번!"

### 1. 씬별 상세 연출 대본

#### 🎬 Scene 01. 엘리베이터 버튼 누르기 규칙 (Elevator Buttons)
* **화면 연출 (POV):** 엘리베이터 탑승. 숫자 버튼들이 벽면에 줄지어 있음. 우리 집은 **7층**.
* **PECS 선택:**
  ```
  +--------------------------+    +--------------------------+
  |      [ 7️⃣ 7층 1번만 ]    |    |      [ 🔢 모든 버튼 다 ]  |
  |     우리 층 버튼 1번 콕  |    |     1층부터 다 누르기    |
  +--------------------------+    +--------------------------+
  ```
* **결과 연출:** `7층` 버튼을 누르자 7번에 주황색 불이 들어오고, 이웃 주민들이 "예의 바르게 잘 누르네!" 칭찬.

#### 🎬 Scene 02. 문이 열릴 때 기다리기 (Doors Opening)
* **화면 연출:** `땡-!` 7층 도착. 문이 열림.
* **인터랙션:** 먼저 내리는 어른들이 지나간 후 한 걸음 앞으로 걷기 (Tap).
