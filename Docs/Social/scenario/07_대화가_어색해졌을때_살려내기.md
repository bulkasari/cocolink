# [실전 시나리오 07] 대화가 어색해졌을 때 살려내기
## : "대화가 뚝 끊겼어요!" — UCLA PEERS / Frankel & Wood Chapter 6 기반 대화 복구(Conversation Repair)

> **원전 레퍼런스:** 《Social Skills Success for Students with Autism》 Chapter 6 (Improving Conversational Comprehension & Repair Strategies)  
> **에피소드 코드:** `PEERS-07-CONVERSATION-REPAIR`  
> **핵심 화용 기술:** 상대방 말을 못 알아들었거나, 침묵이 흐르거나, 화제가 끊겼을 때 도망치지 않고 **대화 복구 문장(Repair Statements)**으로 대화 살려내기  
> **타깃 상황:**
> - 친구가 웅얼거리며 말해서 무슨 말인지 못 알아들었을 때 멍하니 있거나 엉뚱한 대답을 하는 상황
> - 1문답 후 할 말이 없어서 어색한 침묵이 흐르는 상황
> 
> **상태 변수:**
> - `conversation_repair_skill` (대화 복구 숙련도: 0~100)
> - `clarification_confidence` (되묻기 자신감: 0~100)
> - `rapport_recovery` (라포 복구 성공: Boolean)

---

## 1. UCLA PEERS 대화 복구 3대 골든 룰

1. **못 알아들었을 때는 아는 척하지 말고 솔직하게 되묻는다:**  
   👉 *"미안, 주변이 시끄러워서 못 들었어. 다시 말해줄래?"*
2. **침묵이 흐를 때는 친구에게 열린 질문을 던진다:**  
   👉 *"너는 주말에 뭐 했어?"*
3. **대화 끈을 이어주는 다리(Bridge) 단어를 쓴다:**  
   👉 *"그렇구나! 나도 그거 좋아하는데~"*

---

## 2. 씬별 상세 연출 및 인터랙션 대본

### 🎬 Scene 01. 대화 끊김 상황 1: 웅얼거리는 친구 (Unclear Speech)
* **화면 연출 (POV):** 급식실. 맞은편에 앉은 친구(동현이)가 밥을 먹으며 웅얼웅얼 말함: "우물우물... 뫄뫄... 어제 로봇... 웅얼..."
* **내면 당황:** "무슨 말인지 하나도 안 들렸어... 어떡하지? 그냥 웃고 말까?"
* **속마음 위험 경고:** `[💭 아는 척하고 엉뚱한 대답을 하면 친구가 이상하게 생각해요!]` ⚠️

---

### 🎬 Scene 02. 대화 복구 1: 정중하게 되묻기 (Ask for Clarification)
* **PECS 카드 선택:**
  ```
  +----------------------------------+    +----------------------------------+
  |    [ 👂 💬 "다시 말해줄래?" ]      |    |     [ 🤐 멍하니 딴청 피우기 ]     |
  |  "미안, 밥 먹느라 못 들었어!     |    |    못 알아듣고 바닥만 쳐다보기   |
  |   한 번만 다시 말해줘!"          |    |                                  |
  +----------------------------------+    +----------------------------------+
  ```
* **결과 연출:** `[다시 말해줄래]` 선택 시 동현이가 꿀꺽 삼키고 또렷하게 말함: "아! 어제 새로 나온 변신 로봇 만화 봤냐고 물어봤어!" (`clarification_confidence: +40`).

---

### 🎬 Scene 03. 대화 끊김 상황 2: 어색한 침묵 깨기 (Breaking the Awkward Silence)
* **화면 연출:** "응, 봤어." 한마디 하고 3초 동안 어색한 침묵이 흐름. 
* **효과음:** `귀뚜라미 우는 소리 찌르르...`
* **대화 살려내기 인터랙션 (Question Bridge):**
  * 친구에게 질문 던지기 카드를 터치하여 핑퐁 살리기!
  * **PECS 멘트:** `[💬 "너는 어떤 로봇이 제일 멋있었어?"]`
* **결과 연출:** 동현이가 눈을 반짝이며 "나는 파란색 드래곤 로봇! 불 뿜는 게 대박이었어!"라며 신나게 대화를 이어감 (`conversation_repair_skill: 100`).
* **보상:** `[🎙️ 대화 심폐소생술 마스터 배지]` 획득!
