# [스토리보드 & 프롬프트 명세] CocoLink 에피소드 07 & 08: 감정 조절과 문제 크기 분별
## : Everyday Speech식 Size of the Problem & 감정 신호등 쿨다운(Calming Tools)

> **에피소드 코드:** `EP-07-EMOTIONAL-MELTDOWN` & `EP-08-LOSING-GRACEFULLY`  
> **핵심 주제:** 자기 조절 — 실패/실수 시 멜트다운 예방, 승패 수용, 회복 탄력성(Resilience)  
> **상태 변수:**
> - `emotional_arousal` (감정 흥분도: 0~100, 초기값: 80, 목표: 20 이하)
> - `coping_strategy_usage` (진정 도구 사용 숙련도: 0~100)
> - `resilience_score` (회복 탄력성 점수: 0~100)

## PART 1. [EP-07] 내 뜻대로 안 될 때: 블록 타워가 와르르!

### 1. Everyday Speech 핵심 기법: 3단계 문제 크기 (Size of the Problem)

```
┌────────────────────────────────────────────────────────────────────────┐
│                        문제 크기와 나의 반응 크기 매칭                      │
├─────────────────────┬──────────────────────┬───────────────────────────┤
│ 🟢 작은 문제 (Small) │ 🟡 중간 문제 (Medium) │ 🔴 큰 문제 (Big/Emergency)│
│ "혼자서 해결 가능!"    │ "어른의 도움이 필요해"  │ "즉시 멈추고 119/선생님!"  │
│ 예: 블록 무너짐, 연필 부러짐│ 예: 장난감 고장, 친구와 다툼│ 예: 피가 남, 화재, 큰 부상  │
│ ➔ [대응: 심호흡 3번]   │ ➔ [대응: "도와주세요"]  │ ➔ [대응: 큰소리로 알리기]   │
└─────────────────────┴──────────────────────┴───────────────────────────┘
```

### 2. 씬별 상세 연출 대본

#### 🎬 Scene 01. 사전 상황 & 사건 발생 (The Trigger)
* **화면 연출 (POV):** 내 키보다 높게 정성껏 쌓아 올린 알록달록한 블록 탑. 마지막 꼭대기 별 블록을 올리려는 순간, 바닥이 삐끗하며 블록 탑이 `와르르!` 무너짐.
* **사운드 연출:** 우당탕 요란한 블록 무너지는 소리 + 심장 박동 `쿵- 쿵- 쿵-` 효과음.
* **화면 효과:** 화면 테두리가 붉은색으로 깜빡이며 긴장감 조성 (`emotional_arousal: 85`).

#### 🎬 Scene 02. 문제 크기 분별 인터랙션 (Size Check)
* **나레이션:** "어머나! 열심히 쌓은 블록이 무너졌어요. 속상하고 화가 나요. 이 문제는 얼마나 큰 문제일까요?"
* **UI 인터랙션:** 화면 중앙에 3단계 신호등 카드 등장.
  ```
  +------------------+    +------------------+    +------------------+
  |    [ 🟢 초록 ]    |    |    [ 🟡 노랑 ]    |    |    [ 🔴 빨강 ]    |
  |  다시 쌓으면 되는   |    |    선생님 도움이   |    |    피가 나고     |
  |    작은 문제      |    |     필요한 문제    |    |     크게 다침    |
  +------------------+    +------------------+    +------------------+
  ```
* **결과 피드백:** 
  * `[🟢 작은 문제]` 선택 시: "맞아요! 다친 곳은 없어요. 다시 쌓으면 되는 작은 문제예요!"

#### 🎬 Scene 03. 감정 쿨다운 인터랙션: 풍선 불기 호흡 (Calming Tool)
* **화면 연출:** 화면 중앙에 파란색 풍선 등장.
* **인터랙션 (Hold & Release):**
  * **[1회차]:** 3초간 꾹 누르면 풍선이 커지며 `후---` 숨 들이마시기 ➔ 손을 떼면 `하---` 내쉬기.
  * **[2회차]:** 한 번 더 `후---` ➔ `하---` (화면의 붉은 테두리가 온화한 주황색으로 변화).
  * **[3회차]:** 마지막 깊은 호흡 ➔ 풍선이 반짝이며 황금빛으로 터짐 (`emotional_arousal: 20`으로 감소).

#### 🎬 Scene 04. 긍정적 재시도 선택 (Retry)
* **PECS 카드 선택:**
  ```
  +--------------------------+    +--------------------------+
  |      [ 🧩 다시 쌓기 ]    |    |     [ 💥 발로 차기 ]     |
  |   "더 튼튼하게 쌓아보자!"|    |    남은 블록 다 던지기   |
  +--------------------------+    +--------------------------+
  ```
* **결과 연출:** `[다시 쌓기]` 선택 시 1인칭 손이 나와 바닥에 넓은 블록을 깔며 "이번엔 아래를 넓게 쌓아야지!" 나레이션. `[🌟 회복 탄력성 마스터 배지]` 획득.

## PART 2. [EP-08] 게임에서 졌을 때: 씩씩하게 "축하해!" 말하기

### 1. 씬별 상세 연출 대본

#### 🎬 Scene 01. 가위바위보/보드게임 패배 상황 (Losing Moment)
* **화면 연출 (POV):** 친구와 1:1 보드게임. 주사위를 던졌는데 친구 말이 결승선에 먼저 도착함.
* **친구 반응:** "야호! 내가 이겼다!" 만세를 부름.
* **내면 감정:** 화면 구석에 번개 아이콘 ⚡과 함께 속상한 마음 게이지 상승.

#### 🎬 Scene 02. 속마음 관찰 & 생각 전환 (Perspective Taking)
* **속마음 말풍선:** 
  * 친구: `[💭 "열심히 해서 이기니까 기분 좋다!"]` 😄
  * 나: `[💭 "나도 이기고 싶었는데... 너무 아쉬워"]` 🥺
* **생각 전환 나레이션:** "게임은 이길 수도 있고 질 수도 있어요. 친구가 이겼을 때 축하해주면 다음 게임이 더 즐거워져요!"

#### 🎬 Scene 03. 1인칭 행동 선택 (Good Sport Action)
* **PECS 카드 선택:**
  ```
  +--------------------------+    +--------------------------+
  |      [ 🤝 축하해! ]      |    |      [ 😭 엎어버리기 ]    |
  |  "축하해! 한 판 더 하자" |    |     보드판 뒤엎고 울기   |
  +--------------------------+    +--------------------------+
  ```
* **분기 연출:**
  * **[축하해 선택 시]:** 1인칭 손으로 박수를 치며 "축하해! 잘했어!" 말함 ➔ 친구가 "고마워! 너도 정말 잘했어, 다음엔 네가 이길지도 몰라! 한 판 더 하자!" 하며 주사위를 건넴.
  * **보상:** `[🏆 멋진 스포츠맨 배지]` 획득.
