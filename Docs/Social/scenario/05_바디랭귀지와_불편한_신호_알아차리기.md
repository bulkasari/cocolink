# [실전 시나리오 05] 바디랭귀지와 불편한 신호 알아차리기
## : "친구가 싫어하는 몸짓을 보냈어요" — Fast Track Session 19 & 20 기반 비언어 단서(Body Cues) 감지

> **원전 레퍼런스:** 《Fast Track Friendship Group Manual》 Unit V, Session 19 (Noticing Your Friend's Feelings) & Session 20 (Attending to Body Language)  
> **에피소드 코드:** `FT-05-BODY-LANGUAGE-CUES`  
> **핵심 화용 기술:** 친구가 직접 "그만해"라고 말하지 않아도, 표정(찡그림), 몸짓(뒤로 물러남, 팔짱), 시선 회피 등의 신체 신호를 읽고 행동 멈추기  
> **타깃 상황:**
> - 친구에게 장난을 치거나(간지럼, 끌어안기) 계속 말을 거는데, 친구가 뒤로 물러서며 굳어지는 상황
> 
> **상태 변수:**
> - `body_cue_detection` (비언어 신호 탐지도: 0~100)
> - `stop_unwanted_action` (불편한 행동 즉시 멈춤: Boolean)
> - `personal_boundary_respect` (개인 경계 존중도: 0~100)

## 1. Fast Track의 4대 '불편한 신체 신호' (Uncomfortable Body Cues)

```
┌────────────────────────────────────────────────────────────────────────┐
│                   친구의 "불편해요 / 그만해요" 몸짓 신호 4가지           │
├─────────────────────┬─────────────────────┬────────────────────────────┤
│ 1. Face (얼굴 표정) │ 2. Body (몸의 방향) │ 3. Arms/Hands (팔과 손)    │
├─────────────────────┼─────────────────────┼────────────────────────────┤
│ • 미간 찌푸리기     │ • 한 걸음 뒤로 물러남│ • 팔짱을 꼭 끼고 있음     │
│ • 눈 마주치지 않고   │ • 몸을 옆으로 홱    │ • 손바닥으로 밀어내거나    │
│   딴 데 쳐다보기    │   돌려버림          │   몸을 웅크림              │
└─────────────────────┴─────────────────────┴────────────────────────────┘
```

## 2. 씬별 상세 연출 및 인터랙션 대본

### 🎬 Scene 01. 장난과 불편한 신호 발생 (The Uncomfortable Cue)
* **화면 연출 (POV):** 교실. 친구(소율이)가 조용히 스티커북을 붙이고 있음.
* **내 행동:** 소율이 옆에 바짝 붙어서 간지럼을 태우고 어깨를 툭툭 치며 계속 장난을 걺.
* **소율이의 비언어 신호 (Look):**
  * 소율이가 미간을 찌푸리며(😟) 몸을 반대쪽으로 홱 돌림.
  * 양팔로 스티커북을 가슴에 꼭 껴안고 고개를 숙임.
* **소율이 속마음:** `[💭 "나 지금 스티커 붙이고 싶은데... 자꾸 치니까 너무 귀찮고 싫어"]` 😣

---

### 🎬 Scene 02. 비언어 단서 스캔 인터랙션 (Scan the Clues)
* **나레이션:** "잠깐! 소율이가 말은 안 했지만, 몸으로 신호를 보내고 있어요! 소율이의 불편한 신호를 찾아 터치해 볼까요?"
* **인터랙션 (Body Cue Tap):**
  * 화면에서 **[찌푸린 미간]**과 **[몸을 돌린 등]**을 탭하기!
  * 탭할 때마다 `[💡 1. 찡그린 표정!]`, `[💡 2. 뒤로 물러난 몸!]` 알림 팝업.

---

### 🎬 Scene 03. 행동 멈추고 한 걸음 물러서기 (Step Back & Respect)
* **PECS 카드 선택:**
  ```
  +----------------------------------+    +----------------------------------+
  |    [ 🛑 🚶 한 걸음 물러서서 멈추기 ]|    |     [ 🤪 더 세게 간지럼 태우기 ]  |
  |  "소율아 미안! 혼자 하고 싶구나"  |    |    소율이 귀에 소리 지르며 장난 |
  +----------------------------------+    +----------------------------------+
  ```
* **결과 연출:** `[한 걸음 물러서기]` 선택 시:
  * 1인칭 시점이 한 걸음 뒤로 물러나며 자기 자리에 앉음.
  * "소율아, 방해해서 미안해! 다 하고 나면 같이 놀자."
  * 소율이가 안도하며 표정을 풀고 "응, 이거 다 붙이고 놀자!" 밝게 미소 지음 (`personal_boundary_respect: 100`).
* **보상:** `[👀 바디랭귀지 탐정 배지]` 획득!
