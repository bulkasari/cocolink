## PART 1. [EP-05] 장난감 나눠 쓰기와 타이머 시각화

### 1. 씬 흐름 요약표

| 씬 코드 | 시점 / 형식 | 핵심 인터랙션 / 연출 | 교육 포인트 |
| :---: | :---: | :--- | :--- |
| **S01** | 3인칭 동화 | 블록 놀이방에서 멋진 공룡 장난감을 발견한 상황 | 소유권과 공유 개념 도입 |
| **S02** | 3인칭 대비 모델 | 코코가 친구 손에 든 공룡을 낚아채서 친구가 울음 | 속마음: `[💭 깜짝 놀랐어! 슬퍼]` |
| **S03** | 3인칭 긍정 모델 | 코코가 1분 모래시계를 보여주며 "다 쓰고 빌려줘!" 성공 | 긍정적 대안 제시 |
| **S04** | 1인칭 POV 실사 | 친구가 로봇을 갖고 놀고 있을 때 다가가기 (Tap) | 거리 유지 및 정면 접근 |
| **S05** | 1인칭 POV 인터랙션| **PECS 선택:** `[⏱️ 1분만 기다릴게]` vs `[🤖 뺏기]` | 타협과 대기 전략 |
| **S06** | 1인칭 POV 보상 | 타이머 종료 후 친구가 로봇을 건네며 함께 합체 놀이 | 상호 협력 성공 경험 |

### 2. 1인칭 POV 핵심 인터랙션 상세
* **화면 연출 (S05):** 1인칭 시점. 또래 친구가 바닥에서 파란색 변신 로봇을 조립하고 있음.
* **속마음 말풍선:** 친구 머리 위 `[💭 "나 지금 날개 끼우는 중인데..."]`
* **PECS 카드 선택:**
  ```
  +--------------------------+    +--------------------------+
  |      [ ⏱️ ➔ 🤝 ]         |    |         [ 🖐️ 뺏기 ]        |
  |   "다 쓰면 빌려줘!"      |    |      손으로 낚아채기     |
  +--------------------------+    +--------------------------+
  ```
* **결과 피드백:** 
  * `[다 쓰면 빌려줘]` 선택 시: 화면 구석에 10초 타이머가 작동하고, 친구가 "응! 날개 끼우고 바로 줄게!"라며 10초 후 웃으며 로봇을 건넴.

## PART 2. [EP-06] "나도 같이 놀자!" 또래 놀이 3단계 진입법

Everyday Speech의 검증된 **Play Entry 3-Step (관찰하기 ➔ 칭찬하기 ➔ 합류 요청)** 프레임워크 적용.

```
[ Step 1. Observe (관찰) ] ➔ [ Step 2. Comment (칭찬/호응) ] ➔ [ Step 3. Ask (요청) ]
  "친구들이 뭘 하고 있지?"         "우와! 성이 진짜 높다!"         "나도 벽돌 하나 쌓아도 돼?"
```

### 1. 씬별 상세 연출 대본

#### 🎬 Scene 01. 1단계: 관찰하기 (Observe from a Distance)
* **화면 연출 (POV):** 모래놀이터에서 두 명의 아이가 커다란 모래성을 쌓고 물길을 내며 웃고 있음.
* **나레이션:** "친구들이 재미있는 놀이를 하고 있어요. 먼저 친구들이 무엇을 하는지 살펴볼까요?"
* **인터랙션 (QTE):** 모래성 영역을 **[관찰 돋보기 탭(Tap)]**
* **효과:** 화면이 살짝 확대되며 친구들의 대사가 자막으로 뜸: "여기 물길을 더 깊게 파자!"

#### 🎬 Scene 02. 2단계: 칭찬하고 관심 표현하기 (Compliment & Connect)
* **화면 연출 (POV):** 한 걸음 다가가며 친구들과 눈을 맞춤.
* **PECS 카드 선택:**
  ```
  +--------------------------+    +--------------------------+
  |        [ 🏰 👍 ]         |    |        [ 💥 부수기 ]       |
  |   "모래성 진짜 멋지다!"  |    |     모래성 발로 차기     |
  +--------------------------+    +--------------------------+
  ```
* **결과 연출:** 칭찬 카드를 누르면 1인칭 엄지척 제스처와 함께 "진짜 멋지다!" 음성 출력. 친구들이 고개를 들고 활짝 웃으며 "고마워! 우리가 30분 동안 만들었어!" 응답 (또래 수용도 +40).

#### 🎬 Scene 03. 3단계: 도구를 들고 역할 제안하며 묻기 (Offer & Ask to Join)
* **화면 연출 (POV):** 내 손에 노란색 모래 삽과 물뿌리개가 쥐어져 있음.
* **PECS 카드 선택:**
  ```
  +--------------------------+    +--------------------------+
  |     [ 🪣 "같이 하자!" ]   |    |    [ 🏃 장난감 뺏기 ]    |
  |  "내가 물 길어다 줄까?"  |    |     친구 삽 뺏어서 파기  |
  +--------------------------+    +--------------------------+
  ```
* **결과 연출:** 친구들이 "와! 물뿌리개 필요했는데! 여기 물 부어줘!" 하며 자리를 좁혀 자리를 내어줌.
* **보상 연출:** 함께 물을 붓고 깃발을 꽂으며 세 아이의 손이 모여 하이파이브! `[🌟 놀이터 인싸 배지]` 획득.
