# Graphic Concept References (안과 그래픽 컨셉 에셋)

이 폴더는 소아 안과(Eye Clinic) 에피소드 제작을 위한 단계별 컨셉 이미지 레퍼런스 저장소입니다.

## 📂 폴더 구조 및 용도

1. **`2d_storybook/` (Step 1: 사전 동화용)**
   - 자극이 적고 따뜻한 2D 수채화/파스텔 그림책 스타일
   - 주요 에셋: `coco_bear_2d_storybook.jpg` (노란 스카프를 매고 눈을 비비는 아기 곰돌이 코코)

2. **`3d_animation/` (Step 3: 3D 기계 관찰용)**
   - 장난감/비닐 질감의 3D 캐주얼 모델링 (마리오 3D 월드 감성)
   - 기계(자동검사기, 턱받침, 안압 바람) 공간감 및 시연 적응 완충

3. **`real/` (Step 4: 1인칭 실사 체험용)**
   - 실제 소아 안과 환경(검안사, 진료실, 펜라이트, 세극등) 1인칭 POV 실사
