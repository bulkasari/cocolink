# CocoLink 시장 조사 — 사회성 훈련 (Everyday Speech형)

> **시점:** 2026-08-22  
> **위치:** 병원 MVP 완료 이후, **코코에코 다음 제품**  
> **질문:** Everyday Speech처럼 사회성 훈련 커리큘럼을 만들면 시장이 있는가, 누구의 어떤 고통이 돈으로 바뀌는가.

이 폴더는 제품 기획서가 아니다. **사는지 / 왜 사는지 / 어디서부터 팔지**를 고정하기 위한 시장 문서다.

병원 모듈(`Docs/Hospital`, `Docs/Master`)은 이미 “한 상황(병원)을 예측 가능하게 만들어 순응시키는” 파이프라인을 검증 중이다. 사회성 훈련은 그 파이프라인을 **일상 사회 상황 라이브러리**로 확장하는 일이다.

## 한 줄 결론

한국에는 Everyday Speech를 **번역해 팔 자리**가 없다.  
있는 자리는 **치료실에서 배운 사회성을 집·놀이터·어린이집에서 써먹게 하는 한국어 상황 훈련기**다. 병원 MVP가 그 첫 장면이다.

## 제품 계보 (이 문서가 가정하는 라인)

```
코코에코 (언어·따라말하기 / 가정 훈련)
        ↓
코코링크 병원 경험하기 (MVP, 고불안 상황 1개)
        ↓
코코링크 사회성 (Everyday Speech형 상황 라이브러리)  ← 이 폴더
```

코코에코가 언어의 **형태(말)** 를 다루면, 사회성 모듈은 언어의 **쓰임(언제·누구에게·어떻게)** 을 다룬다. 둘은 같은 아이, 같은 부모, 같은 치료 일정 위에 붙는다.
