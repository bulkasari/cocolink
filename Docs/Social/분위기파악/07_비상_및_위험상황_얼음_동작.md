# [분위기 파악 07] 비상 및 위험 상황 "얼음!" 동작
## : "선생님이 '멈춰!'라고 하셨어요" — Emergency Danger Zone 스캔 & 즉시 동작 멈추기

> **상황 코드:** `ROOM-07-EMERGENCY-FREEZE`  
> **공간 레벨:** Level 0 (Danger / Emergency Zone - 위험·비상)  
> **핵심 과제:**
> - 소방 대피 훈련 사이렌이 울리거나, 선생님이 위험 상황에서 엄한 목소리로 "모두 멈춰!"라고 외쳤을 때
> - 장난이나 농담으로 받아들이지 않고, 즉시 하던 행동을 멈추고 제자리에 '얼음'하기
> 
> **상태 변수:**
> - `emergency_reaction_time` (비상 정지 반응 시간: 초, 목표: 1초 이내)
> - `serious_tone_awareness` (엄격한 목소리 톤 인지도: 0~100)
> - `safety_compliance` (안전 지시 준수 완료: Boolean)

---

## 1. 씬별 상세 연출 및 인터랙션 대본

### 🎬 Scene 01. 3초 룸 스캔: 엄격한 목소리와 사이렌
* **화면 연출 (POV):** 복도에서 친구들과 공놀이를 하고 있음.
* **사건 발생:** 
  * 선생님이 정색한 표정으로 두 손을 번쩍 들며 외침: **"모두 멈춰! 제자리에 서세요!"**
  * 저 멀리서 뜨거운 조리실 카트가 지나가는 위험 상황.
* **시각 단서 (Look):**
  * 선생님의 눈이 크고 단호함. 웃음기 전혀 없음.
  * 다른 친구들이 모두 자리에 딱 멈춰 섬.
* **청각 단서 (Listen):**
  * 크고 단호하며 경고성이 짙은 엄격한 목소리.
* **나레이션:** "선생님 목소리가 아주 엄하고 진지해요! 이건 장난치는 시간이 아니에요. [위험하고 중요한 비상 상황]이에요!"

---

### 🎬 Scene 02. 즉시 동작 멈추기 (Instant Freeze QTE)
* **인터랙션 (Freeze Touch):**
  * 화면에 커다란 파란색 **[❄️ 얼음! 버튼]**이 깜빡임.
  * **1초 이내에 빠르게 탭(Fast Tap)**하여 하던 동작을 완전히 멈추기!
* **결과 연출:** 공을 던지려던 손이 딱 멈추며 화면이 꽁꽁 얼어붙는 안전 연출 (`emergency_reaction_time: 0.8초`). 뜨거운 카트가 안전하게 지나감.

---

### 🎬 Scene 03. 선생님의 안전 지시 따르기 (Follow Instructions)
* **선생님 대사:** "다들 잘 멈춰주었어요. 이제 벽 쪽으로 한 줄로 붙어서 걸어가세요."
* **PECS 카드 선택:**
  ```
  +----------------------------------+    +----------------------------------+
  |    [ 🚶 벽에 붙어서 줄 서기 ]     |    |    [ 🏃 장난치며 뛰어다니기 ]    |
  |  (선생님 지시대로 차분히 이동)   |    |    선생님 말 무시하고 달리기    |
  +----------------------------------+    +----------------------------------+
  ```
* **결과 연출:** 벽 쪽으로 안전하게 이동하자 선생님이 안도하며 "선생님 말에 즉시 멈춰줘서 다치지 않았어요. 정말 훌륭해요!" 칭찬.
* **보상:** `[🛡️ 안전 수호 히어로 배지]` 획득!
